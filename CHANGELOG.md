# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Monster Manual 2024 Spanish translation module foundation
- Babele compendium mapping configuration for MM content
- Spanish translations for the Monster Manual introduction, usage guide and appendix material
- translated compendium entries for monster content, actor data, features and roll tables
- localized art handouts and A-to-Z content sections
- credits, licensing and attribution documentation for the module

### Fixed
- corrected converter function names and metadata wiring in the content pipeline
- corrected untranslated references and missing entries in the monster compendium dataset
- corrected cross-reference mismatches and mapping inconsistencies between content and actor entries
- corrected missing names, alignments and localization metadata in monster actor definitions
- corrected feature and table labels, counts and translation mappings
- corrected final validation issues across the MM 2024 Spanish translation flow

### Changed
- reorganized the translation workflow into dedicated content, actor, feature and table passes
- refined the Spanish localization across monster entries, appendices and narrative descriptions
- standardized the Babele mapping and validation workflow for translated MM entries
- improved the release preparation and documentation flow for the module packaging process
